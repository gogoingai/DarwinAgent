## 验收口径

原生恢复验收要求 `ExecutionSelection()` 的 daily 路径。模型和工具步骤须有 Workspace 请求、内容引用与完整回执；中断后不得重复已保存步骤。完成后再次继续必须同时满足执行成功、循环证据完整与新增 HTTP 为零。
