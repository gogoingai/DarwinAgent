## 操作说明与实际限制

完整使用方法见 [中文续跑指南](../workspace-continuation.zh-CN.md)、[English continuation guide](../workspace-continuation.md)、[Wiki 查询说明](../wiki-query-continuation.md) 与 [English Wiki guide](../en/wiki-query-continuation.md)。

1. 活跃 Python 代码、连接或执行配置变更在安全边界暂停，重启 executor 后继续；不做任意代码热更新，不恢复半个 token。已成功内容和历史费用不会清空。
2. 自定义 evaluator 要提供 `configure_evaluation` 或实际已有的设置属性。不支持的私有设置会明确报错；没有标准编号的历史评分不作为可靠同条件比较。持出集 campaign 继续保留独立冻结协议，日常训练入口支持局部续跑。
3. 主动预算心跳间隔一秒；强制杀进程可能遗漏最后不足一秒的主动时间，不会把离线时间补计为费用。实际 HTTP 尝试单独原子登记。
4. 向量阶段校验和登记已有冻结向量；没有指定嵌入配置／原输入时报告缺口，不自行寻找模型或补生成。原图／原原文缺失的旧检查点保留为未知来源。
5. Wiki 权限依赖登记的来源类型及引用链，不能判断任意未结构化文本是否被外部调用者虚假标成训练材料。部分归纳、损坏对象及不可容纳的片段均保留缺失／待办，不能宣称范围全部完成。
6. 本次没有跑全量 LoCoMo 或 TravelPlanner，没有证明优化收益。五题自然语言 fixture 的原始字符串精确匹配为 0/5，保留原评分；字段及原文核对是另一份有限验收。额外六题使用独立 JSON 字段校验，6/6。记录实际 HTTP、token 与主动时间，不推算供应商未提供的货币费用。
