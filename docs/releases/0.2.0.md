# DarwinAgent 0.2.0

2026-10-09 · [GitHub Release](https://github.com/gogoingai/DarwinAgent/releases/tag/v0.2.0) · [Changelog](../../CHANGELOG.md)

## 中文

这次更新让 S 的修改实际进入 LLM 构图，并让 Wiki 和提案器获得图、事实、工具与审查轨迹的诊断线索。单题审查耗尽可以独立恢复，成功进度和失败原件继续保留。

- **按当前资产构图：** S 声明实体、字段与关系，P.extract 指导生成；节点和边必须有事实编号、来源与逐字证据。修改 S/P.extract 会重建图，固定事实和向量保持不变。
- **共同诊断 S/F/C/P：** 反馈包含图结构、未物化声明、空检索、检查拒绝与资产修改线索，提案器可以向 Wiki 查询对应原件。这些线索需要证据核对。
- **显式数据输入：** LoCoMo 从命令指定的 HF 仓库或本地目录加载，运行记录锁定提交与文件校验值。原始数据与实验产物不纳入 Git，也不隐式读取历史快照。
- **单题恢复：** 审查器收到此前修订历史；审查耗尽独立分类，同一阶段只给失败题一次新响应恢复机会。再次失败保留执行故障，不能伪装成语义拒答。已恢复故障与当前测量完整性分别报告。
- **展示与配置：** README 图片不写版本号，GitHub/PyPI 徽章动态显示版本；支持通用的思考模式配置和按证据 ID 查询 Wiki。

升级包：

```bash
python -m pip install --upgrade darwinagent==0.2.0
darwinagent --version
```

也可安装本 Release 附带的 `darwinagent-0.2.0-py3-none-any.whl`。LoCoMo 接入代码位于仓库，须在检出源码后安装基准依赖并运行：

```bash
uv sync --extra benchmarks
uv run python -m datasets.locomo.run \
  --dataset-repo justis-xu/memory-eval-zh --dataset-revision main \
  --arm g1 --train-only --cases conv-26 --rounds 2 \
  --output runs/locomo-0.2.0
```

模型连接由操作者配置。新 g1 运行默认 LLM 构图、Wiki 优化和 S/F/C/P 修改范围；复用已有事实/向量须显式指定 `--memory-root`，v0 与 frozen/projection 模式均要求此参数。代码或构图输入变化后使用新的输出目录，历史实验保持原状。只有对话模型时，新记忆包明确声明无向量模式。

实现已通过 590 项框架测试（8 项外部资源跳过）、18 项 LoCoMo 测试、11 项 TravelPlanner 测试与安装包回放/续跑验收。发布时另核对版本、构建产物与远端 CI。离线故障回归不证明真实模型质量提升，也不代表完整 LoCoMo 基准成绩。

## English

This release makes S revisions affect LLM graph construction, exposes original graph/fact/tool/review evidence to Wiki and the proposer, and recovers isolated review failures without discarding successful progress.

- Build evidence-bound auxiliary graphs under current S and P.extract while retaining frozen facts and vectors. Every generated node and edge requires a fact ID, registered source and verbatim evidence.
- Expose S/F/C/P diagnosis signals and focused Wiki evidence queries. Signals are hypotheses to verify against originals.
- Require explicit HF or local LoCoMo input, pin content per run and remove implicit historical snapshot dependencies.
- Preserve review revision history, classify feedback exhaustion separately, and give settled failed questions one fresh retry per stage. Archive originals, reuse healthy checkpoints, retain retry budgets across resume and disclose incomplete comparisons.
- Keep README graphics versionless and release badges dynamic; support generic thinking configuration.

Install with `python -m pip install --upgrade darwinagent==0.2.0`, or use the wheel attached to the GitHub Release. The repository contains the LoCoMo adapter; install benchmark dependencies in a checkout to use its commands.

**Migration:** New g1 runs default to LLM graphs, Wiki optimization and S/F/C/P scope. Specify `--dataset-repo` or `--data-dir`. Existing memory must be selected with `--memory-root`; v0 and frozen/projection modes require it. Use a fresh output directory after code or construction-input changes. Model configuration remains operator supplied, and graph-only memory explicitly declares that no vector model was configured.

**Validation:** The implementation passed 590 framework tests (8 external-resource skips), 18 LoCoMo tests, 11 TravelPlanner tests and installed-wheel replay/resume acceptance. Release version, distributions and remote CI are checked separately. Recorded recovery proves mechanics; it does not establish model-quality gains or full LoCoMo results.
