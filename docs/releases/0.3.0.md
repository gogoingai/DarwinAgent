## 交付变化 / Delivered changes

- Agent 自己控制循环；任务、文件产物和 episode 直接进入执行与实验。独立适配器和 ReAct
  共用 `AgentContext`、固定工具/profile 与持久化回执。
- V4 S 投影带来源的图；F 使用受限异步解释器；C 覆盖动作前后与交付；P 使用固定角色槽位。
  现有提案、Wiki、准入、独立评测与版本保留服务承载新实验。
- 未知请求不自动重发；已知读失败支持结构化恢复；写工作区按 episode 隔离。
- 历史可选 LIFT 容器机制路径包含 Docker、delta 加载和 trace 回读，录制响应只验证机制。
  本轮 MiniMax 使用原生内容协议的本地执行适配；核心 wheel 不依赖基准集成。

Agent-owned loops consume direct task/artifact episodes. V4 source-bound graphs, bounded
async functions, lifecycle checks and role prompts flow through the existing proposal/Wiki/
admission/evaluation/retention services. Durable receipts, known-read recovery and unknown
quarantine preserve execution evidence. Optional native LIFT stays outside the core wheel.

## 安装与兼容 / Installation and compatibility

```sh
uv sync --frozen --group test
uv build
python -m pip install dist/darwinagent-0.3.0-py3-none-any.whl
python -m darwinagent.demo.agent_runtime --output runs/agent-offline
```

Python 3.11+ 用于核心；Python 3.12 用于固定原生内容协议的可选本地执行环境。
V3 文件字节、指纹和历史不重写，默认图问答 API/CLI 保留。
新 backend 需要显式接入；改身份后新建目录，旧运行用原来的冻结环境恢复。
0.3.0 的架构版本已明确授权，普通兼容更新仍只增加末位 C。

Core Python is 3.11+; the optional LOCAL native-protocol environment uses pinned Python 3.12. V3 bytes,
fingerprints/history and default graph-QA behavior are preserved. Opt into the new backend;
changed identity requires a fresh run, while old runs retain their original frozen environment.
The architectural 0.3.0 choice was explicitly authorized; routine compatible releases remain patch-only.
