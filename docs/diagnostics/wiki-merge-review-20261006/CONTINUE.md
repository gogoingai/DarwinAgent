每轮目标 5–10 分钟，配置整轮 900 秒预算。同步原生调用的真实墙钟退出仍需短验实测，若超时仍不返回，先修隔离或熔断，不能继续刷满十轮。B0 尚不受候选轮时限控制，应单独记录耗时与监控进度；不能把“候选有时限”描述成整个运行都不会停滞。

首次确认框架故障或同类超时重复出现时，执行 agent 应结束对应运行、保留现场并修复，不能继续刷满十轮消耗时间；正常评分后拒绝候选则继续。训练入口当前没有接入 `STOP` 文件，停止时须确认具体运行进程，勿假设写 `STOP` 就会生效。

记忆事实及向量索引冻结并核对摘要；图按当前 S 重建。这里“从零”是资产与优化 Wiki 从零，**不重新抽取记忆**。P.extract 不运行，不得把它的改动报告成有效优化。允许联合调整有效的 S/F/C/P，不限制每轮只动一个类别。

```bash
cd /Users/xu/git/oak

  --output "$OAK_SHORT_ROOT" --arm g1 --convs conv-26
```

模型预检失败则停止该目录的后续命令。保持源码、模型、划分和规则不变时才能 `--resume`；修代码后保存原目录并以新身份重验。不要运行中修改源码、删除故障题、降低采纳门槛或覆盖历史成绩。

短验必须核对旧 q39 类冲突：原文已否定的派生记忆，不能被“列表完整性”审查重新强制加入。若仍复现，修通用证据优先级及审查规则，不加题号特例、不改冻结事实。题不在新训练划分中时，用独立诊断目录复查原故障；诊断仅证明修复，不能并入新循环成绩。

## 外测入口与收益验收

现有 `datasets.locomo.scripts.external_test` 直接加载冻结旧图，**尚未接入新图重建模式**；不能直接拿它的旧入口宣布本方案外测完成。执行 agent 需先增加显式可选图重建参数，默认保持原行为，并确保预检与 Pipeline 同用 `rebuild_snapshot_graph`。将整个 `graph_rules.py` 的摘要、资产 S 摘要及实际图摘要记入外测身份；旧图缓存不得复用为新模式证据。用离线小例验证入口后再开始三对话外测。

最小比较只做锁定 G1 与纯向量。纯向量在相同冻结记忆/索引、模型、作答/审查与判题配置上运行，固定 K=30，不在测试对话调参；记录其资产版本，明确两臂可比条件。阶段六才全量评测这三段对话，阶段四与五不跑整段题库。

最终分开给结论：①框架是否完成且无运行故障；②Wiki 是否存下准入/准出、运行/策略经验，误验证是否消除，后续提案引用是否有效；③质量是否改善。输出每轮训练/验证成绩、采纳理由、耗时、提案次数、Wiki 更新与引用、S/F/C/P 实际差异及图节点/边/路径变化；再给三对话两臂正确率、宏平均和故障率。若只跑通而无提升，如实报告，不宣布 Wiki 有收益；测试结束后不拿测试错题继续优化同一版本。
