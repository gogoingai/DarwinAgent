## 尚未解决的两个反例

证据：本目录 `remaining-probes.json`；使用当前源码，无真实模型调用。

1. Travel `two_day_consistent` 正例第一天 `current_city=Rockford`、三餐为空。合理的“非移动日必须有三餐” C 被此 `must_pass` 正例拒绝。正例还没有独立的匹配证据图，仍取当前案例图的行作证据。修复应使用带完整参数和自洽证据的小型独立 fixture，并经过官方约束校验；不能靠放松 C 使错误正例通过。

以上不意味着全部修复无效，也不足以宣布当前候选可正式合并。

## 新实验的最小方案（以此版本为准）

目标：在相同记忆、相同向量索引上，完整走通新资产初始化、图构建、训练归因、Wiki、联合提案、准入、冒烟、评分、验证选版、采纳和多对话终测，同时缩短单轮反馈。保持现有运行模式和冻结历史不变，新增独立实验模式与目录。此实验验证图与召回策略的价值；不验证记忆重抽的收益。

| 环节 | 具体要求 |
| --- | --- |
| 划分 | 在 conv-26 内固定随机种子和题目清单，目标 15 题训练、10 题验证；题数/分组不足时明确调整。数据层按题型分层，将高度相似或针对同一事实的题尽量放在同组；题型和 gold 不进入生成。保留原 case_id/question_id。另固定至少三个本次不参与训练/验证的对话用于最终测试，例如已有快照的 conv-42、conv-43、conv-50。不要每个对话重新训练。 |
| 新初始化与固定记忆 | 新生成 S/F/P/C、新建 Wiki，不继承旧优化经验；每个对话的事实内容、事实 ID、来源、时间字段与向量索引固定并校验摘要。纯向量与图策略使用相同事实和索引。旧事实格式和 Oak MemoryResult 不同，导入适配必须保留内容和 ID，不得悄悄重抽或修正事实。构图不能额外从原文抽取仅图侧可见的新事实；原文证据接口在两侧保持一致。 |
| 图可变 | 从固定事实生成当前 S/构图规则的图，保留事实锚点并允许有来源的派生结构变化。当前 GraphAssembler 支持固定事实锚点和 S 声明的物化视图，不能仅添加任意 schema 关系就宣称实际生成了边；新规则必须有实际构图实现和验证。优先复用现有声明机制，避免此轮顺带做无限制关系生成框架。若能力不足需明确报告。 |
| 训练 | B0 后完整运行 R1–R10，每轮固定同一组 15 道训练题，保留当前完整准入/冒烟/审查/评分门槛。训练小集收益只能作为继续迭代的信号。不要把 10 次提案尝试写成 10 个正式轮次。 |
| 重试和时限 | 新模式每轮最多 3 次提案，总耗时目标 5–10 分钟、上限 15 分钟；从提案开始计到 Wiki/决策落盘，包括图重建、准入、冒烟和验证。首次初始化耗时另列。时限不能随重试重置；超时须终止相关工作、持久化阶段与故障，不算正常拒绝或已完成正式轮。目标耗时需实测，不承诺外部服务一定在预算内完成。 |
| 缓存 | 图缓存以固定事实摘要、来源身份、当前 S/有效构图规则和构图实现版本绑定，不能用题目列表或完整资产版本作构图缓存键。F/C/P.tools/P.answer/P.review 改动复用同图；有效构图规则变化时重建一次，在准入/冒烟/正式答题间复用。事实和向量不重建。新资产版本必须重做对应检查与训练答题，不能复用旧答案或旧通过结论。 |
| 提前失败 | 先做廉价结构、合同、已有故障输入重放，再做真实模型冒烟。连续重复同一个确定性故障时明确报出并停止该次运行，避免跨轮反复烧预算。失败事实、准入修复和重查结果写入 Wiki；模型归因失败保留“待归因”。不降低验收条件。 |
| 优化范围 | S/F/C 以及 P.tools/P.answer/P.review 可根据归因联合优化，不要求每轮四类都改。P.extract 在固定记忆实验中不执行；新模式禁止把修改它写成已生效优化。保留原有非冻结模式的优化能力。Wiki 仅用于优化侧，不进入单题作答上下文。 |
| 验证参与循环 | B0 建立固定验证集基线；候选完成训练和准入后，对同一 10 题验证集评分，用于选版和防退化。不在每次提案重试时跑验证。训练逐题轨迹用于 Wiki 归因和提案；验证只返回汇总选版指标，不把逐题 gold、答案、错误诊断交给提案器。验证会影响选择，属于开发集，不能再当最终独立测试。 |
| 多对话终测 | R1–R10 后锁定最终 S/F/C/P、构图规则和配置，在至少三个额外对话各自的固定事实/向量上构图并直接测试。测试用该对话全部约定可评分题，单独记录耗时，不能每轮重复执行。最终版本、B0 和纯向量在相同事实/索引及原文证据权限下比较。测试题、答案和评分反馈不进入 Wiki、提案、准入或冒烟，不根据测试结果回头调参。 |
| 报告 | 每轮记录初始化/提案/构图/准入/冒烟/答题/评分/验证/Wiki/总耗时、提案次数、缓存命中、故障、训练/验证分数及采纳。记录每版事实与向量摘要不变；图摘要、节点/关系类型、增删节点和边、派生结构到事实 ID 的映射、代表题召回路径和证据变化。无图变化也如实报告。终测给出逐对话及汇总的质量、故障、耗时、工具调用收益，不以图变大代替答题收益。 |

开发后先跑无模型合同/状态机与缓存失效验证，再进行真实模型短验；不要直接复用旧 run 目录接着跑，也不要虚构当前尚未支持的 CLI 参数。完整 10 轮结果以正式阶段产物为准；故障未清除则如实标记未完成。
