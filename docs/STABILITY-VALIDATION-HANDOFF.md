以下在 agent 完成上面的运行目录准备及资产准入检查后执行。`RUN_ROOT` 必须是新目录；
启动前确认没有其他 agent 正在使用它。若设置了旧资产副本，仅复制到 `$RUN_ROOT/train/B0/assets`。

```bash
cd /Users/xu/git/oak
RUN_ROOT="/Users/xu/git/oak/datasets/locomo/runs/agentic_stability_$(date +%Y%m%d_%H%M%S)/g1"
mkdir -p "$RUN_ROOT"
PYTHONPATH=. .venv/bin/python -m datasets.locomo.scripts.precheck_agentic \
  --arm g1 --convs conv-26,conv-47,conv-49 --output "$RUN_ROOT" && \
PYTHONPATH=. .venv/bin/python -u -m datasets.locomo.run \
  --arm g1 --scope sfcp --rounds 3 --output "$RUN_ROOT" \
  > "$RUN_ROOT/full-cycle.log" 2>&1
```

这条命令包含 G1 B0、最多三轮优化和既有验证／测试阶段。不使用 `--train-only`
（该入口固定 rounds=0），也不使用 `--train-questions` 截短训练对话。
同代码、同配置、同目录恢复才可给最后一条运行命令添加 `--resume`。
不要用自动换根的看护脚本反复冷启动来替代故障定位。
