# conv-26 固定图双口径实验

本实验用于区分本体证据、检索、作答与评测执行故障。它不复刻官方评测器，也不把原有的 89.4% 当成新口径基线。

- 数据与模型：仓库内中文 conv-26（199 题）；现有 strong/fast 模型；固定 `graph_d0953122`、冻结 schema 与主题词表。该图包含对话抽取以及 observation/event_summary 标注层。
- 宽松：全部必要答案要素正确，允许等义表述、形式和不影响答案的粒度差异。
- 精准：满足宽松，并满足 gold 的精度、限定与承诺强度。
- 两种口径都拒绝关键事实错误、主体错位、矛盾备选和错误附加内容；正确且有依据的补充不扣分。
- gold：原始版和独立审计版分别完整判分。审计不读取系统预测；等义差异不改 gold；不能用粗粒度或不同对象的答案替代缺失细节。争议项保留完整评分，并单列无争议子集。
- 故障：格式、判分、候选核查失败重试后仍不成功时记录执行状态。未完成结果只给完成率与上下界，不发布单一准确率。

## 运行

```bash
uv run python -m datasets.locomo.runs.experiments.run_current_validation
# 阶段也可单独运行：audit / history / answer / diagnose / review
uv run python -m unittest discover -s datasets/locomo/tests -v
```

当前只复评 iter22 基线和唯一一轮优化答案，再做诊断与盲复核。历史复评已停止，已完成结果仅归档，不是验收前置条件。`--stage history` 只用于另行请求的历史评分审计，不应在每次修复验证时运行。

实验目录为 `datasets/locomo/runs/experiments/conv26_dual_v4/`。`manifest.json` 绑定代码、数据、固定图、gold 审计、提示词和模型参数；输入变化时拒绝续跑。初次实现期间的试跑保留在 conv26_dual_v1，但其局部上下文基线已撤回。v4 使用双语完整对话、原始机器图片说明和已有派生标注核验附加事实，搜索词不作事实，每批最多四条匿名请求，逐条独立判分；盲复核采用单条请求检查批次干扰与判分分歧。正式作答运行使用冻结 v2 manifest；该199题答案只生成一次，v4以generation_binding.json验证生成合同后复用原始答案。v2评分因遗漏图片说明撤回；v3未完成成绩已停止。v4完整等价预检保留内部标点、数字与单词边界及上标字符，空答案不短路。

`manual_gold_review.json` 是只基于问题与中英文原始语料的补充审计；不进入作答模块。修改该文件后必须建立新实验版本，不能复用当前实验的判分报告；生成合同一致时可继续使用冻结答案。

## 产物与判断边界

- `gold_audit.json` 保存模型审计原始结果；`gold_audit_reviewed.json` 保存语料复核后的决策；`gold_original.json` / `gold_audited.json` 冻结两套标准。
- `evaluations/` 对每套历史答案及优化答案保存四组指标与逐题判据；`history.json` 区分相同答案的评分变动。历史 checkpoint 未记录图指纹的轮次标记为 unknown，不能追溯性伪造版本绑定。
- `../conv26_dual_v2/optimized/answers.jsonl` 保存结构化答案、引用、完整候选原始输出、实际终答上下文编号和核查轨迹。作答输入没有 gold、QA evidence 或类别。
- `diagnostics.json` 逐要素记录图中存在、进入上下文、正确使用三个状态（yes/no/unknown）。同一出处被任意事实覆盖不视为答案要素覆盖。
- `blind_reviews/` 和 `blind_review_map.json` 分离匿名评测输入与轮次映射。相同问题、gold、答案只复核一次，映射保留所有对应轮次；`blind_disagreements.json` 保留原始判决分歧；分歧由第三次独立原文核验裁决，执行失败仍报告上下界，裁决结果同步应用于匹配的历史答案。
- `comparison.json` 汇总改善、回退、双口径差异、盲复核状态与调用量。出现分歧必须审查，不能仅凭分数宣称系统上限。

只有 conv-26 得到验证，不外推整体 LoCoMo，也不预设 90% 可达或不可达。

## 可复用经验与当前证据

| 问题 | 修复原则 | 当前验证与边界 |
|---|---|---|
| 数字、前缀和猜测拒答被判正确 | 仅允许完整等价短路，其余逐要素检查 | 本地回归测试通过；真实评分仍需盲复核 |
| 局部评测上下文把正确补充误判成捏造 | 评分使用完整来源，明确正文、图片描述与搜索意图的区别 | 本轮早期评分已撤回；不能直接外推其他数据集的来源规则 |
| 候选看到的事实与允许引用的事实不一致 | 从实际候选输入建立引用池，检查编号真实存在 | 193 个成功输出的引用均在各自输入中；内容支持仍由独立核查判断 |
| 空正文、截断或格式失败被算成错误拒答 | 答案、拒答、原始输出和执行状态分开保存 | 本轮 6 个作答执行故障：5 个核查响应连续为空，1 个最终 JSON 截断。状态分离有效，但核查预算与稳定性尚未解决；保留未知与成绩上下界 |
| 引用多、主体字段一致被当作答案质量 | 检查事实支持、主体关系、完整性和内部一致性 | 三候选流程已修改；跨人物推理不能仅凭字段不同而拒答 |
| 修复验证先跑全部历史，迟迟没有当前效果 | 先固定一个基线与一次新作答，历史审计按需单独运行 | 当前收敛为 iter22 对比；不会将历史轮数作为修复验收条件 |

当前已直接核对实际终答输入的病例（非盲复核，索引从 0 开始）：37 题的日落事实 `26-0675` 已进入上下文，答案却采用较早的马/风景画；47 题的导师、家人、朋友事实 `26-0048`、`26-0752` 已进入上下文，答案却只说梅拉妮。这两例支持作答损失。55 题的梅拉妮日落事实 `26-0675` 未进入最终事实上下文，支持上下文遗漏。它们不说明全部题目的损失比例，也不证明当前候选筛选方案已经解决这些问题。

进一步核对原始候选与核查轨迹后的失败结论：

- 37 题三个候选都遗漏最新日落事件，核查器只比较较早的马/风景画，仍将其中一个标为完整。形式上的 `complete=true` 没有验证时间限定和整个输入的覆盖。
- 47 题存在朋友/家人的候选，核查器却把未限定具体事件的问题擅自解释成徒步冲突，排除了该候选。核查理由不能替代对问题范围的证明。
- 197 题三个初始候选都拒答，第一次核查也正确指出公路旅行属于梅拉妮；拒答复核却将相邻对话和卡罗琳的发言当作共同活动证据，推翻正确拒答。允许跨人物推理不能放宽为同场发言即共同参与。
- 强制候选核查增加了新的执行依赖。6 道核查执行故障保持未知，状态记录修复不等于可用性改善；不能通过删除故障题或只看 193 道成功题来宣称进步。

这些答题改动不得作为成功方案迁移。下一次作答修复应先在上述少量反例中验证时间限定、问题范围、关系链及核查故障处理，再决定是否运行完整样本；不得继续用大规模复评代替这些机制验证。

迁移到其他数据集时，先核对题目定义、标准答案、完整来源和不可回答规则，再决定日期、计数、列举及图片证据的适用方式。不能直接沿用 LOCOMO 的 gold 修复或逐题规则；测试病例也不进入生产作答提示词。
