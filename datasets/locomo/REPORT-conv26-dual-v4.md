# conv-26 固定图：作答与评测瓶颈验证

状态：已完成实验流程。范围只含 conv-26 的 199 题。
结论：执行状态分离、引用池与统一判分的修复已验证；新候选筛选流程仍存在漏项、事件误选和核查执行故障。本轮优化答案没有优于 iter22，不能将它作为已验证成功的作答方案推广。

## 核心判断与修复优先级

**当前首要问题是作答流程不能可靠地使用已有证据，候选核查和拒答复核又会放大错误。提示词设计有具体问题，但尚不能将全部下降归因于提示词或模型能力。**

审计 gold 下宽松确认正确数从159降到151：改善6题、回退10题，另有4道基线正确题成为执行故障。6道故障中另外2道基线已错。gold审计对前后宽松成绩都增加5题，所以gold修正不能解释这轮退步。

| 因素 | 当前证据 | 能作出的判断 |
|---|---|---|
| 作答与后处理 | 37题日落事实在输入中，核查仍选较早的马/风景画；47题擅自限定成徒步事件；197题三候选正确拒答被复核改成错误共同活动 | 已确认局部机制失效。先修问题范围、时间限定、关系链和正确拒答保护，不应先换模型或放宽gold |
| 提示词 | 终答规则要求具体细节缺失时回答相关事实；核查器用完整性布尔判断，却没有可靠检验必要要素；跨人物规则被解释成同场发言即共同活动 | 混淆相关性与事实支持、缺乏可核验的约束。属于具体设计问题；单凭一次联合改动不能量化各提示词的贡献 |
| 检索/上下文 | 156道有具体gold题中，模型诊断13题必要要素在图内但未进终答上下文 | 存在上下文选择瓶颈。不能用换终答模型修复未提供的事实；该13题为模型诊断，非逐题人工确认 |
| 数据表达/建图 | 有具体gold题中，模型诊断11题至少一个要素缺于图；其中包含争议书名题。海报文字等原始图片信息没有充分进入图 | 局部建图缺失和来源歧义并存。不能等同于数据集无效或理论上限；本轮未改图 |
| 数据集/gold | 18条修复审计保留5、撤销12、争议1；43题按当前gold定义为不可回答 | 局部gold与译文/图片来源问题确实存在，需要审计。没有依据将整个数据集归为错误；全部43题的不可回答合理性未做独立gold审计 |
| 模型/接口 | 模型保持固定；5道新增核查连续空正文，1道截断；197题同一模型先正确拒答再错误改答 | 输出稳定性与新增强制核查依赖共同造成故障。未比较其他模型、未做组件消融，不能断言模型上限或证明换模型有效 |

156道有具体gold题：新答案宽松正确116；其余分为图内缺失11、上下文遗漏13、上下文足够但作答损失8、执行故障6、未知2。43道不可回答题：35道正确拒答、8道错误作答；它们不计入缺失正向答案事实的图内损失。宽松正确的116题中还有6题精准不足。此拆分仅用于诊断，评分和原始诊断未改。

建议优先验证37、47、197等已确认反例及核查故障处理，只使用问题和实际图证据，固定当前模型。随后分别验证上下文选择；建图与gold缺失单独处理。没有消融证据前，不将任何单一组件宣称为全部退步的原因，也不推广本轮失败的候选筛选。

## 复现与边界

- `manifest.json` 固定代码、提示词、模型、数据、图、schema、主题词表与 gold 审计指纹。历史答案和冻结输入没有覆盖。
- 运行期间工作区四个并发/路由文件发生变化；本进程使用启动时加载的冻结代码。`frozen_code/` 已保存全部 37 个源码文件并逐一核对冻结指纹；`workspace_drift.json` 记录漂移。没有覆盖当前工作区的新修改；当前树直接续跑会被指纹检查拒绝，复现需在独立检出中使用冻结源码和输入。
- `question_differences.json` 保存全部 199 题原始/审计标准、前后答案、四组逐题判据及要素诊断。
- `delivery_summary.json` 保存指标、改善与回退索引、要素状态、运行进度和调用台账分组。
- `same_answer_scoring_changes.json` 单列相同答案的旧评分增益/回退，以及同一冻结答案从v2到v4的评分变动；这些不算作答提升。
- v1、v2、v3 成绩均已撤回。v4保留数字与单词间边界；核查双语完整对话、已有图片描述与派生标注，图片搜索词不作事实。唯一一轮优化作答冻结在v2目录，v4只重新评分和诊断。
- 生成调用从v2冻结时间窗计数；评分调用来自v4独立台账。缓存响应单列，不冒充新增API调用。
- 已保存作答轨迹记录 1610 次逻辑调用响应（含缓存）；旧 iter22 报告未保存可比调用量，不能补造调用增量。
- 未跑全量十段，不预设 90% 可达或不可达，不外推整个 LOCOMO。
